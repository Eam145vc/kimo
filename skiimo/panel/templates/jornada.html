Configuración de jornada

Define el horario oficial. El sistema clasifica cada marcaje según estas horas y aplica la tolerancia para determinar si está "puntual" o "fuera de tiempo".

Horario oficial

Tolerancia

Margen de ±N minutos en cada hito. Si el marcaje cae dentro de este rango, se considera puntual y el cálculo usa la hora oficial.

Define a qué hora empiezan oficialmente las extras (ej. salida 17:00 + 30 = 17:30). Solo se usa para el KPI "Tarde extras". El cálculo real usa los marcajes extra_in/extra_out.

Cómo se cuentan las horas

Regla universal: el empleado nunca gana tiempo extra, solo puede perder por llegar tarde o irse temprano. Las horas extras se calculan aparte con marcajes explícitos.

🟢 Entrada (oficial )

  • Antes de : cuenta como (no gana tiempo)
  • Después de : hora real (pierde el exceso)

🔵 Salida almuerzo (oficial )

  • Antes de : hora real (pierde tiempo de trabajo)
  • Después de : cuenta como (no gana tiempo)

🔵 Regreso almuerzo (oficial )

  • Antes de : cuenta como (no gana tiempo)
  • Después de : hora real (pierde por llegar tarde)

🟠 Salida (oficial )

  • Antes de : hora real (pierde, se va temprano)
  • Después de : cuenta como (no gana, aunque se quede más)

⏰ Horas extras

Solo se cuentan si el empleado marca extra_in y extra_out después de la salida. El tiempo extra = extra_out − extra_in.

Si el empleado se queda hasta las 19:00 pero no marca extras, no gana horas extras. Quedarse después de la hora sin marcar = no pago adicional.

Aplicar a marcajes existentes

Re-clasifica los marcajes ya registrados usando la jornada y tolerancia actuales. No toca los que fueron editados manualmente desde el panel.
